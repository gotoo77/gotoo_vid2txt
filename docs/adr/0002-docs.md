# ADR-0002 : mdBook + rustdoc plutôt que Sphinx

- **Statut : proposé**
- **Décision :** mdBook pour le manuel Markdown, rustdoc pour l'API, GitHub Actions pour construire les deux. README concis qui renvoie vers le manuel.
- **Justification :** stack native Rust, sources en Markdown, maintenance inférieure à Sphinx + Python pour un projet entièrement Rust.
- **Alternative :** Sphinx si besoins spécifiques (documentation multi-langue, domaines spécialisés) apparaissent. Ne pas l'ajouter à titre préventif.
- **Critère :** `mdbook build` et `RUSTDOCFLAGS='-D warnings' cargo doc --no-deps` réussissent dans la CI ; liens vérifiés séparément si outillage ajouté.
